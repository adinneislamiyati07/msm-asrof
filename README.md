# msm-asyrof-website
Website PT. Asyrof Fadel Ali | MSM ASYROF

## Google Maps untuk lokasi penjemputan

Pemilih titik memerlukan API key Google Maps Platform dengan Maps JavaScript API aktif dan billing Google Cloud yang dikonfigurasi. Isi nilai `googleMapsApiKey` di `script.js` dengan browser key, lalu batasi key menggunakan HTTP referrer domain website. Jangan gunakan key tanpa pembatasan.

Pelanggan dapat mengklik peta untuk menetapkan titik. Koordinat dan tautan Google Maps akan disertakan dalam pesan reservasi WhatsApp. Selama API key belum diatur, lokasi teks tetap dapat dikirim secara manual.
